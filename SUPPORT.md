# Support

Use the public issue tracker for reproducible bugs, documentation gaps and focused feature proposals. Include the deployment profile, Node version, relevant error code and redacted logs. Do not attach credentials, audio, transcripts, databases or delivery payloads.

Questions about operating the demo should start with `studio/RUNBOOK.zh-CN.md`. Architecture and AI extension questions should reference `docs/ARCHITECTURE.md` and `studio/docs/ai-development/START-HERE.md`.

Security vulnerabilities and leaked credentials are not support issues; report them privately according to `SECURITY.md`.
